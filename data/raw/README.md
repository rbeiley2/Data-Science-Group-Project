# NBA Games Data

This data is an updated version of the original [NBA
Games](https://www.kaggle.com/datasets/nathanlauga/nba-games) by Nathan Lauga.

- [Data source](https://www.nba.com/stats)
- [Code](https://github.com/Nathanlauga/nba-data-scrapping)
- **Updated to**: 2025-02-13

The dataset retains the original format and includes the following files:

- `games.csv` ‚Äì Summary of NBA games, including scores and team details.
- `games_details.csv` ‚Äì Detailed player statistics for each game.
- `players.csv` ‚Äì Player information.
- `ranking.csv` ‚Äì Daily NBA team rankings.
- `teams.csv` ‚Äì List of all NBA teams.
